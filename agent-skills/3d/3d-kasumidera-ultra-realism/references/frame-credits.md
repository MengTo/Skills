# Visual study credits

The six images are frames from the Kasumidera journal soundwalk recorded with DreamCut. The source is 3840 × 2160 at 60 fps. The study presents 1920 × 1080 copies. The 2× button inspects an image crop. To judge live perspective, set the game camera to 2× as described in the skill.

| Frame | Time in the 40-second recording |
| --- | --- |
| Torii gate | 7.60 s |
| Under the eaves | 16.80 s |
| Bridge | 29.30 s |
| Near ridge | 35.30 s |
| Clouds in the pass | 38.70 s |
| Field journal | 5.00 s |

The buildings and bridge were modeled for Kasumidera. The scene uses CC0 Poly Haven scans and Seedream-generated botanical and paper artwork. Terrain combines edited GSI elevation and aerial imagery with Mapzen Terrain Tiles, USGS GMTED2010 and SRTM data, and modified Copernicus Sentinel data (2024).

Clouds shown in these frames use the Walt Disney Animation Studios Cloud Data Set, © 2017 Disney Enterprises, Inc., which credits Kevin Udy’s *Colorado Clouds* reference photograph. The project resampled, rearranged and relit the field. The adapted cloud data is licensed under Creative Commons Attribution-ShareAlike 3.0 Unported.
