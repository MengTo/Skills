## Minimal prompt

Use $interactive-topography. Build a timeline atlas and a raised relief with interactive elevation contours.

## Recreate the demo

Use one generated coastal terrain with ridges and inlets. Draw a plan view with thin minor contour lines and a stronger line every fifth elevation interval. Overlay a dotted route, three stations and their years. Brighten nearby lines when the pointer passes them. Let each year button select its own station from the keyboard. Add a Field Access view that raises the same elevations into a shaded relief over a quiet contour background. A press should send an outward wave from its exact location. Start particles at stable positions, give them a short outward kick only as the crest reaches them, then let them settle. Make the pulse reach the opposite corner even when it starts near an edge.

## Remix prompt

Use the same technique for a glacier survey. Replace the shore with a saddle between two peaks and verify the contour paths through the pass at a narrow viewport.
