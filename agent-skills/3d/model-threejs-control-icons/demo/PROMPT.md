# Model Three.js control icons

## Minimal prompt

Use $model-threejs-control-icons. Model a set of instrument icons that read clearly in small buttons.

## Recreate the demo

Use $model-threejs-control-icons. Build a fountain pen with a clip and nib, a ribbon microphone with a yoke and grille, and a glass hourglass with sand and a brass frame. Arrange them in a three-button tray. Render them with the same orthographic projection, filtered environment lighting and multisampled transparent atlas. Selecting a button gently turns that instrument.

Give the pen a narrow highlight along its clip, put readable negative space inside the microphone yoke, and expose the sand through the hourglass frame. Use a pale key and warm return on the metal. Verify the edges at two device scales and make keyboard selection visible even when motion is reduced.

## Remix prompt

Use $model-threejs-control-icons. Replace the instruments with a camera, a loupe and a mechanical timer while keeping their visual weight consistent.
