# Perching Butterfly

## Minimal prompt

Use $perching-butterfly to build perching butterfly for a botanical field guide.

## Recreate the demo

Build a standalone, responsive browser study of perching butterfly for a fictional botanical field station named Alder. Animate a small 3D butterfly that banks in flight, approaches an actual plant surface, settles with hinged wings and takes off when disturbed. Build four citrus-and-charcoal wing surfaces and a real branch. Provide a deterministic way to trigger departure and watch a gentle return. Include reduced-motion handling, local dependencies and a legible phone layout. Test the interaction from a fresh load and after resizing to a narrow phone. Preserve a stable reading surface while decorative layers move. Inspect both the resting frame and the midpoint of the interaction, including focus visibility, readable contrast and graceful behavior when motion is reduced.

## Remix prompt

Adapt the study to a coastal field station. Preserve the interaction, readable hierarchy and keyboard behavior while changing the colors, shapes and editorial copy.
