Line

Ink #1d1b1a stroke 2.3, round caps and joins, one long smooth cubic path per figure; code glyphs 1.8; coral stripes 1.9; code dashes 2.3.

Rules

  • Draw the figure as one wandering line, with an eye stroke apart.
  • Colour patches sit behind the line, offset 2-6 px, wobbly.
  • Coral, periwinkle and white only, on warm beige paper.
  • Stripes on tops are coral lines that stop short of the contour.
  • No ground plane: a squiggle or a curl under the feet.
  • Big joyful action poses; hands and feet as small loose loops.
