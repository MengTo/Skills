# Copy patterns

## Launch post

```text
I used [method] to create [specific result].

The useful part is [source-backed mechanism or lesson].

[Verified call to action and destination]

[Disclosure when required]
```

## Resource delivery

```text
Here are the files:

[Bundle]: [verified link]
[Guide or article]: [verified link]
[Full video]: [verified link]

[One immediately useful tip from the source]
```

## Follow-up

```text
The resources from my [topic] video are ready.

[One practical lesson]

[Verified links]
```

Replace every placeholder before activation or publication. Remove absent deliverables instead of promising them.
