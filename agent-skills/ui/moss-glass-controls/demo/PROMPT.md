# Moss Glass Controls

## Minimal prompt

Use $moss-glass-controls to build moss glass controls for a botanical field guide.

## Recreate the demo

Build a standalone, responsive browser study of moss glass controls for a fictional botanical field station named Alder. Build Sylva-style dark glass action pills and woodland cards with an inset rim, pale icon well and a gradient that travels around the edge on hover. Pair one primary pill with an inset fern card. Animate only their perimeter, support keyboard focus and let each open its own note. Include reduced-motion handling, local dependencies and a legible phone layout. Test the interaction from a fresh load and after resizing to a narrow phone. Preserve a stable reading surface while decorative layers move. Inspect both the resting frame and the midpoint of the interaction, including focus visibility, readable contrast and graceful behavior when motion is reduced.

## Remix prompt

Adapt the study to a coastal field station. Preserve the interaction, readable hierarchy and keyboard behavior while changing the colors, shapes and editorial copy.
