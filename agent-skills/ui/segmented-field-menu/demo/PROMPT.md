# Segmented Field Menu

## Minimal prompt

Use $segmented-field-menu to build segmented field menu for a botanical field guide.

## Recreate the demo

Build a standalone, responsive browser study of segmented field menu for a fictional botanical field station named Alder. Create an inset upper-right navigation dock with compact icon-and-label segments, a pale selected segment and a matching footer dock for an editorial landing page. Put the dock in the upper right of a woodland hero and repeat it in the closing section. Make all anchors, selected states and narrow-screen icon labels work. Include reduced-motion handling, local dependencies and a legible phone layout. Test the interaction from a fresh load and after resizing to a narrow phone. Preserve a stable reading surface while decorative layers move. Inspect both the resting frame and the midpoint of the interaction, including focus visibility, readable contrast and graceful behavior when motion is reduced.

## Remix prompt

Adapt the study to a coastal field station. Preserve the interaction, readable hierarchy and keyboard behavior while changing the colors, shapes and editorial copy.
