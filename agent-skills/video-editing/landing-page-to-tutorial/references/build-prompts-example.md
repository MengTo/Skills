# The Codex prompts, word for word

## The one line that starts each build

The design tool's Build page gives you one line to paste into your coding agent. It was the first and only prompt for each first pass:

```
Create a web page implementation from the following instructions: [private build link]
```

The link is private to the the design tool file, so it is replaced here. You get your own from Build page in the design tool.

Model: GPT-6.2 Astra in Codex, extra high.
