# Compose a Woodland Landing Page

Start with a single landscape and decide what each return to it reveals. In the hero reserve a low, full-bleed band for a large foreground branch, a quiet upper-left area for the promise, and a compact dock at upper right. Extend the branch geometry laterally for an edge-to-edge composition. Frame the highest offshoot and keep the main controls clear of the crown at both portrait and ultrawide sizes.

Follow with a pale Journey spread pairing three observation steps with a specimen. Each step updates both its explanation and the figure. Re-enter the grove at a different camera position for a Story with one readable field note and shot controls. Give Testimonials a quieter light surface. Keep the quoted voice and attribution together. Use dark Pricing cards with the hero’s image insets, pill actions and icon wells. Close on the forest with oversized type and a usable return link.

Repeat a single type family, faint outer guides and a consistent primary action. Change section spacing according to the amount of reading. Reveal groups in reading order. Let word-level reveals finish early enough to read normally. For reduced motion render completed text and stable camera positions.

Walk the full page by pointer, touch and keyboard. Test direct section links, reversing direction during an entrance, and returning from the footer. The six sections should make sense with all animation paused.
