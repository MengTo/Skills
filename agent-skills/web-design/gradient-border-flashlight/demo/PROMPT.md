## Minimal prompt

Use $gradient-border-flashlight. Light adjacent gradient borders with a single page-wide pointer flashlight.

## Recreate the demo

Place three notebook cards in a grid on a dark page. Give each one a restrained permanent gradient border, a rounded corner and a disclosure that can be opened by keyboard or pointer. Listen for movement at the page level. Position a broad soft light in local CSS coordinates for every visible card close enough to catch it. Clip a stronger version of the light to a one-pixel border ring. Crossing the gap should illuminate both facing edges while the opposite ends stay quiet. Keep the effect aligned while scrolling under a stationary pointer. Fade on document exit. Preserve the focus outline, and leave touch and forced-color visitors with a readable ordinary card.

## Remix prompt

Apply the lighting to a staggered dashboard. Increase the radius for wider gutters, then compare the shared edge of two small panels with the full perimeter of a large one.
