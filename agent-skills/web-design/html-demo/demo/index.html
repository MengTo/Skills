HTML Demo

Fil for Mac making a picture, drawn live in HTML. Every frame is draw(t): the app at 1200 × 750, built once a step and set from the step's clock alone, then scaled to this window by one number. Drag the clock and the window shows exactly that frame. Leave the state to timers instead and it couldn't: no jumping to a step, no still for reduced motion, no two screenshots alike. No video, canvas or WebGL.

From fil.design/download, where Fil for Mac's windows are drawn this way. The skill: fil.design/skills/html-demo.
