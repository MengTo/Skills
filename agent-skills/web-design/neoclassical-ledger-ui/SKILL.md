# Neoclassical Ledger UI

Use the page as an illustrated ledger. Couple each financial or studio action to an object with a readable silhouette, such as a folded invoice, an open journal, or linked brass rings. Separate material, text and rules so the same visual system survives at phone size.

Extracted from the Folvra studio ledger. Open the [working example](demo/index.html) and its [recreation prompt](demo/PROMPT.md).

## Establish the paper

Start with paper #efe2c8, lighter sheet #f9eed7, ink #2c241b, body #514537, muted #695841 and rule #cdbb98. Tile a low-alpha continuous grain beneath content. Place a faint engraved impression in selected open areas. Keep the center of text blocks clean.

## Set the hierarchy

Use one or two large sans words for a chapter, a book serif for editorial sentences and a mono face for ledger categories. The Folvra specimen uses Geist Sans, Serif and Mono. A chapter title can grow from 62px to 156px; compare its longest word with the available phone width. Start metadata at 11px. Keep each word together during letter reveals.

## Compose the spread

Use a two-column folio for four services. Reserve one side of each entry for its cutout and the other for an index, title and brief explanation. Size the art by visible ink bounds. Preserve open paper around the fingers, rings or page edges. Use a broken ink rule between entries and one thin vertical rule at the column split. On narrow screens stack entries and place the art clear of the body copy.

## Check paper and ink

Inspect the first and last lines of every heading at 390px. At desktop size, read each service from the title to the object to the note. Check the same page with grain disabled. If text becomes easier to read, lower the grain. Use the Painted Product Showcase skill when a moving product UI is the focus.
