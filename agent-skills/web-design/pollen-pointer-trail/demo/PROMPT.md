# Pollen Pointer Trail

## Minimal prompt

Use $pollen-pointer-trail to build pollen pointer trail for a botanical field guide.

## Recreate the demo

Build a standalone, responsive browser study of pollen pointer trail for a fictional botanical field station named Alder. Emit a sparse, distance-spaced trail of airborne pollen from the pointer over a woodland scene, with depth drift, short lives and bounded particles. Emit pale drifting grains along pointer paths, reset on leave and keep touch scrolling functional. Include reduced-motion handling, local dependencies and a legible phone layout. Test the interaction from a fresh load and after resizing to a narrow phone. Preserve a stable reading surface while decorative layers move. Inspect both the resting frame and the midpoint of the interaction, including focus visibility, readable contrast and graceful behavior when motion is reduced.

## Remix prompt

Adapt the study to a coastal field station. Preserve the interaction, readable hierarchy and keyboard behavior while changing the colors, shapes and editorial copy.
