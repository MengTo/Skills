# Sylva Field Guide Layout

## Minimal prompt

Use $sylva-field-guide-layout to build sylva field guide layout for a botanical field guide.

## Recreate the demo

Build a standalone, responsive browser study of sylva field guide layout for a fictional botanical field station named Alder. Lay out a botanical editorial UI with continuous vertical rules, sparse diagonal guides, large lightweight typography and aligned chapter labels and specimen captions. Place a large left-aligned headline and a captioned fern figure on paper, followed by a dark spread with precisely aligned margins. Include reduced-motion handling, local dependencies and a legible phone layout. Test the interaction from a fresh load and after resizing to a narrow phone. Preserve a stable reading surface while decorative layers move. Inspect both the resting frame and the midpoint of the interaction, including focus visibility, readable contrast and graceful behavior when motion is reduced.
